# Local Image Lab

把不同 API 平台的生图 Key 放进同一个页面使用。

Local Image Lab 是一个无需后端、由浏览器直接请求图片模型的本地生图台。它不绑定某一家 API 平台：你可以保存自己的多个 API Key，统一选择模型、提交任务、比较结果，并在某个 Key 额度不足时继续尝试其他可用来源。

在线体验：[local-image-lab-dpbpftgxl8na.edgeone.cool](https://local-image-lab-dpbpftgxl8na.edgeone.cool)

## 为什么做这个项目

不同 API 平台可能提供相同或不同的生图模型，价格、额度和接口格式也各不相同。这个项目把这些差异收进本地配置和请求适配器里，让日常使用只需要关注模型与生成参数，而不用在多个平台页面之间来回切换。

- **自带 Key**：API Key 由你提供，并且只保存在当前浏览器。
- **不绑定平台**：平台、模型、接口格式和价格都由本地目录描述；12API 与火山方舟 Ark 只是当前已经配置好的来源。
- **统一生图入口**：选模型即可生成，同一轮可以调用多个模型对比效果。
- **额度自动接力**：接口明确返回额度不足时，停用当前 Key 并尝试下一个可用来源，也可以手动恢复。
- **纯前端运行**：不需要部署后端，也不会把 Key 写进项目文件或生成历史。

## 主要功能

- 同时调用多个图片模型，并在同一轮中对比结果。
- 在浏览器保存多个 API 平台、多个 API Key；按精确模型、价格和可用度选择请求来源。
- 明确遇到额度不足时自动停用该 Key 并尝试下一个来源，可手动恢复。
- 页面内查看人工维护的模型价格、计费方式和可用度快照。
- 可通过选择、拖拽或剪贴板粘贴追加参考图，并支持排序、预览、单张删除和清空。
- 生成期间仍可修改配置并继续提交；每轮会冻结自己的 Prompt、模型和参考图，随后按顺序执行。
- 保存常用提示词，并与主提示词拼接使用。
- 在浏览器本地保存生成历史，放大图片时同步查看完整生成参数，并支持下载和勾选导出带平台/价格信息的 Excel。

## 本地运行

项目启动时会读取 `data/*.json`，不能直接通过 `file://` 打开。请在项目目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)，在“API 来源”中选择已配置的平台并添加自己的 Key，再选择模型生成。

API Key 只保存在当前浏览器的 `localStorage`，不会写入项目 JSON 或生图历史。请勿将含真实 API Key 的浏览器配置、开发者工具内容或截图提交到仓库。

价格只用于本地选择请求来源和展示预计费用，不会查询真实余额。只有接口明确返回 `HTTP 402` 或目录中配置的余额不足消息时，当前 Key 才会被标记为额度耗尽；超时、`401`、参数错误和其他故障不会自动换 Key。

## 接入自己的 API 平台

项目并不假设所有平台共用一种接口。要接入新的 API 来源，需要先根据该平台的接口文档补充本地目录；如果请求格式不同，再增加对应的前端请求适配器。配置完成后，用户仍然只需要在页面里保存 Key 和选择模型。

- `data/providers.json`：平台线路、模型请求名、适配器和额度错误规则。
- `data/models.json`：生图模型能力、选项和参考图限制。
- `data/pricing.json`：人工维护的价格与可用度快照，当前使用各平台的 `default` 分组。

新增平台时，需要同时添加平台映射、模型能力和价格记录；前端会在启动时校验三份目录之间的引用关系。

## 当前已配置来源

- 火山方舟 Ark：Seedream Images，共 3 个生图模型。
