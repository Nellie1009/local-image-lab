# Local Image Lab

把不同 API 平台的生图 Key 放进同一个页面使用。

Local Image Lab 是一个无需后端、由浏览器直接请求图片模型的本地生图台。它不绑定某一家 API 平台：你可以保存自己的多个 API Key，统一选择模型、提交任务、比较结果，并在某个 Key 额度不足时继续尝试其他可用来源。

在线体验：[local-image-lab-zeu4qa2m.edgeone.cool](https://local-image-lab-zeu4qa2m.edgeone.cool?eo_token=5b6f978568328f37d7eea2ae2787309f&eo_time=1790018139)

## 为什么做这个项目

不同 API 平台可能提供相同或不同的生图模型，价格、额度和接口格式也各不相同。这个项目把这些差异收进本地配置和请求适配器里，让日常使用只需要关注模型与生成参数，而不用在多个平台页面之间来回切换。

## 项目特色

| 特色 | 说明 |
| --- | --- |
| **根据模型自动选择 API Key** | 可以保存多个平台、多个 Key。选择模型后，应用会从支持该模型且当前可用的来源中自动挑选合适的 Key，并参考本地维护的价格与可用度排序。 |
| **额度不足自动接力** | 接口明确返回额度耗尽时，当前 Key 会被置灰，并继续尝试下一个可用来源；额度恢复后可以手动重新启用。 |
| **一轮同时测试多个模型** | 一次生成可以勾选多个图片模型，每个模型都有独立结果区域，方便直观看出同一 Prompt 在不同模型上的效果差异。 |
| **多批次独立生成** | 上一批还在生成时，可以修改 Prompt、参考图和模型并继续提交下一批。每个批次都会冻结自己的配置与素材，互不覆盖，再按队列执行。 |
| **完整的参考图工作流** | 支持点击选择、拖拽或剪贴板粘贴图片；新图片会继续追加，还可以拖动排序、放大预览、单张删除或一键清空。 |
| **常用 Prompt 保存与拼接** | 可以把常用风格、构图或编辑要求保存在浏览器里，生成时手动选择，并自动与本轮主 Prompt 拼接。 |
| **请求 JSON 自检** | 页面保留可展开的请求 JSON，便于核对请求地址、模型、Prompt、参数和参考图是否按预期组装；API Key 与内联图片内容会在诊断信息中脱敏。 |
| **本地生成历史** | 生成结果和文本参数保存在当前浏览器；可以查看大图、完整参数、实际模型与请求来源，也可以逐张下载。 |
| **勾选历史导出 Excel** | 在历史页自由选择要导出的结果，按 Prompt 和不同模型整理为对比表，并保留平台、线路与价格信息，方便做模型评测。 |
| **价格与能力目录透明可查** | 页面内可以查看人工维护的模型价格、计费方式、可用度、尺寸选项和参考图限制，目录使用 JSON 管理，便于继续扩展。 |
| **纯前端、本地优先** | 项目无需后端，API Key 只保存在当前浏览器，不会写入项目文件或生成历史。 |

## 本地运行

项目启动时会读取 `data/*.json`，不能直接通过 `file://` 打开。请在项目目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)，在“API 来源”中选择已配置的平台并添加自己的 Key，再选择模型生成。

API Key 只保存在当前浏览器的 `localStorage`，不会写入项目 JSON 或生图历史。请勿将含真实 API Key 的浏览器配置、开发者工具内容或截图提交到仓库。

价格只用于本地选择请求来源和展示预计费用，不会查询真实余额。只有接口明确返回 `HTTP 402` 或目录中配置的余额不足消息时，当前 Key 才会被标记为额度耗尽；超时、`401`、参数错误和其他故障不会自动换 Key。

## 接入自己的 API 平台

项目并不假设所有平台共用一种接口。要接入新的 API 来源，需要先根据该平台的接口文档补充本地目录；如果请求格式不同，再增加对应的前端请求适配器。配置完成后，用户仍然只需要在页面里保存 Key 和选择模型。

- `data/providers.json`：平台线路、模型请求名、适配器和额度错误规则。
- `data/models.json`：生图模型能力、选项和参考图限制。
- `data/pricing.json`：人工维护的价格与可用度快照，当前使用各平台的 `default` 分组。

新增平台时，需要同时添加平台映射、模型能力和价格记录；前端会在启动时校验三份目录之间的引用关系。
