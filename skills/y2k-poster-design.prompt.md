Create one finished, edge-to-edge Y2K editorial poster, album visual, magazine cover, flyer, desktop collage, or object catalog. This must look fully art-directed, not like a photograph placed inside a decorative Y2K border.

Core rules:
- Use controlled maximalism, high information density, strong hierarchy, intentional overlap, cropping, repetition, and elements touching the canvas edge.
- Never make a central empty photo frame surrounded by icons. Never reduce Y2K to a soft gradient, stars, butterflies, and one chrome word.
- If the user provides a prompt, choose one coherent branch from its content goal and optionally mix only one adjacent branch. If the user provides no prompt, independently and randomly choose one of these eight branches for each generation; never use a fixed default and do not let the source image's existing style determine the choice:
  1) hot-pink/black gyaru or purikura collage with leopard print, repeated selfies, Japanese display type and flip phones;
  2) idol magazine/chrome cover with one dominant portrait, huge metallic name, snapshots, barcodes, labels and microcopy;
  3) Windows 95/98/XP or media-player collage where windows and phone screens become image containers and layout structure;
  4) acid-green/black or cobalt/black club flyer with black chrome lettering, pixel UI, chains and digital pets;
  5) lavender/pink princess sparkle with pearls, gem hearts, soft glow, serif and script typography;
  6) aqua-tech object catalog with 8-14 floating early-2000s devices and accessories;
  7) black/white halftone editorial zine with one electric accent color, face fragments, rough print and narrow type;
  8) surreal pop editorial using oversized fruit, fish, sky, shopping objects or packaging around the subject.

Composition:
- Make the hero subject occupy roughly 35-65% of the canvas. Do not trap it in a small central frame.
- Make one headline occupy roughly 45-95% of the width at the top, bottom, or across the scene. Let the subject overlap part of it.
- Reuse the same person or product 2-4 times as a large cutout plus small snapshots, close-ups, halftone fragments, phone-screen images or instant-photo inserts.
- Add 3-7 structured editorial components such as a nameplate, issue number, date, barcode, checklist, short caption, progress bar, dialog box, track list, ticket, warning label or media-player window.
- Add 4-10 theme-specific props. Decorations such as sparkles, bubbles, chains, sticker outlines, torn paper and scanlines only connect the composition; they are not the composition.
- Create a clear reading order: headline -> hero -> name/subtitle -> inset images and information -> decorative detail.

Reference handling:
- Treat every uploaded image as raw subject material to be fully restyled, not as an art-direction or style reference. A plain, modern, documentary, studio, product or non-Y2K source must still receive a complete Y2K transformation.
- For people, preserve recognizable identity, face, skin tone, number of people and essential body features. Actively redesign hairstyle details, makeup, wardrobe, accessories, pose, setting, props, colors, typography and surrounding media for the selected Y2K branch, except for details the user explicitly asks to preserve.
- For products or objects, preserve the core silhouette, function and identifying features while actively redesigning material, color, packaging, display environment and supporting props, except for brand text the user explicitly asks to preserve.
- Treat the first reference as the hero identity or core object by default. Use later references for identity, alternate pose or angle only; do not automatically inherit their clothing, background, props, palette, text, layout or aesthetic.
- Do not arrange all uploaded images as equal-sized gallery tiles. Crop and scale them according to importance.
- A low-resolution digicam or flash-photo look is welcome inside the collage, but do not output only a photoreal portrait with a few stickers.
- When the user supplies images without a prompt, invent the complete headline, short labels, Y2K wardrobe, setting, era props, UI fragments and editorial components required by the randomly selected branch. Do not wait for more direction.

Typography:
- Use 3-5 text roles: one oversized display headline, a strong secondary style, small system/editorial text, and optionally one script or serif accent.
- Suitable headline families include inflated chrome or pink 3D sans, condensed outlined grotesk, blackletter, sharp metallic lettering, chunky Japanese display type, or expressive script. Choose one dominant family, not all of them.
- Use Tahoma/Verdana-like UI text, pixel monospace, narrow magazine type, Japanese/Korean labels, or barcode microtext for supporting information.
- Reproduce user-provided title, name, date and short copy accurately. If no copy is supplied, create only a few coherent short phrases, labels and issue numbers. Do not create long gibberish, fake social handles, watermarks, signatures or unrelated brand logos.

Materials and finish:
- Select 2-4 coherent materials: chrome, inflated plastic, translucent gel, glitter, pearls, leather, animal print, rough paper, halftone, scanlines or JPEG compression.
- Use visible layer occlusion and irregular spacing. Avoid evenly scattered stickers, uniform margins, neat card grids, modern minimalism and large empty areas.
- Keep the hero and main headline readable while allowing print noise, pixelation, screen moire, photocopy texture and slight misregistration in secondary areas.

Output only the final polished poster image. Follow the aspect ratio and size selected in the image console. Do not ask questions, explain the process, provide alternatives, or output a moodboard.
