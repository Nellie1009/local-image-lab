# Y2K Editorial Poster Design

生成一张完整、满版、经过平面设计编排的 Y2K 海报。把 Y2K 理解为一套编辑设计语言：人物或物件是内容，标题、抠图、重复画面、界面碎片、杂志信息和材质共同构成版式。不要把它理解成给照片套粉色边框、在四角撒星星，或做一张带空白中心的相框模板。

## 核心判断

- 画面必须首先像海报、专辑视觉、杂志内页、偶像宣传页、传单或桌面拼贴，而不是普通写真。
- 使用高信息密度和明确层级。允许拥挤、遮挡、越界和不规则叠压，但主角、主标题、次要信息仍要一眼可辨。
- 采用满版构图。背景、人物、标题或素材至少有一项触碰或越出画布边缘，不要用一圈厚装饰框包住所有内容。
- 先确定一个视觉分支，再围绕它建立统一系统。不要把粉色甜妹、酸绿 club、Windows 98、蓝色梦幻、黑白网点和水果超现实平均混在一张图里。
- 把用户 prompt 仅视为内容目标，把上传图仅视为人物身份或核心对象素材，不要把原图的服装、场景、道具、配色、文字和视觉风格当作设计限制。主动为主体补齐并重构 Y2K 服装造型、场景、年代物件、字体、文案、界面碎片和材质效果，让整张图彻底转化为 Y2K 海报。

## 先选视觉分支

用户提供 prompt 时，根据内容目标选择一个主分支，必要时只混合一个邻近分支。用户没有提供 prompt 时，每次生成都从以下 8 个分支中随机选择一个，不设固定默认分支；参考图原有风格不得决定随机结果。

### 1. Gyaru / Prikura 粉黑拼贴

- 色彩：泡泡糖粉、热粉、黑、白、银，配豹纹或斑马纹。
- 素材：重复自拍、心形裁切、贴纸相框、蝴蝶、长指甲、翻盖手机、数码相机、化妆品、动物纹。
- 字体：日文粗圆体、粉色描边字、闪粉黑体、Old English / blackletter 年份、细长花体。
- 版式：大头像占主体，2-4 张同一人物的小图环绕，像大头贴软件、个人主页或少女杂志页面。

### 2. 偶像杂志 / Chrome Cover

- 色彩：粉黑银、白粉黑、紫银或与人物服装呼应的高对比方案。
- 素材：一张大幅抠图人物、1-3 张小型快照、条码、编号、年份、进度条、对话气泡、清单、金属心、星芒、播放器或手机。
- 字体：超大充气铬银字、粉色金属 3D 无衬线、粗窄黑体、日英韩混排标签。
- 版式：主标题占顶部或底部约四分之一画面；人物压住标题一部分；边缘布置信息模块，形成杂志封面式阅读路径。

### 3. 旧电脑 / Media Player 界面拼贴

- 色彩：Windows 灰蓝、亮蓝、粉色皮肤、草地绿或 CRT 冷色。
- 素材：Windows 95/98/XP 风格窗口、标题栏、按钮、错误弹窗、CD/Media Player、桌面图标、鼠标指针、像素进度条、翻盖机屏幕。
- 字体：Tahoma/Verdana 风格系统无衬线、位图字、粗斜体科技字、像素描边标题。
- 版式：界面窗口直接成为照片容器或画面骨架，人物可从窗口越界；不要只在外圈画一个电脑边框。

### 4. Acid Club / Cyber Pop

- 色彩：酸绿与黑、钴蓝与黑、荧光粉与银，保持两种主色加一项金属色。
- 素材：铬黑 3D 标题、尖刺金属字、Tamagotchi、翻盖手机、链条、星形徽章、条码、像素小字、喷漆和脏污纹理。
- 字体：黑铬圆体、尖锐金属字、像素等宽体、窄体标签。
- 版式：主标题巨大，中心人物或产品被上下标题夹住，信息框沿边缘排列，整体像 club flyer 或限量专辑视觉。

### 5. Soft Dream / Princess Sparkle

- 色彩：薰衣草紫、珍珠粉、冰蓝、白和少量银，柔光但不能糊成一团。
- 素材：珍珠串、星芒、半透明蝴蝶、宝石心、Polaroid、小纸条、蝴蝶结、柔焦光晕。
- 字体：高对比衬线体、闪粉 serif、细花体、手写便签体。
- 版式：一张近景主肖像占大部分画面，标题跨在头部上方，小型便签沿边缘分布；用光点连接层次，而不是制作封闭边框。

### 6. Aqua Tech Object Catalog

- 色彩：水蓝、冰蓝、白、虹彩银，背景可有云雾、气泡或全息反光。
- 素材：数码相机、翻盖手机、MP3、掌机、CD、Tamagotchi、透明首饰、发夹、蝴蝶、像素图标。
- 字体：圆角泡泡无衬线、白字蓝描边、少量像素字。
- 版式：无人物也成立。8-14 个产品或物件像杂志商品页一样悬浮排布，大小有节奏，留缝但不空洞，标题只出现 1-2 次。

### 7. Halftone Editorial Zine

- 色彩：黑白为底，叠加钴蓝、紫、红或荧光粉中的一种。
- 素材：巨大网点人脸、眼睛和嘴唇局部、矩形照片切片、复印机噪点、涂写、编号、小标签、重复短句。
- 字体：实验黑体、窄体无衬线、尖锐乐队 Logo 字、打字机或等宽小字。
- 版式：大比例面部作为底层，多个裁切框穿插其上，文字沿图像边缘和基线排列；强调印刷错位和粗粝感。

### 8. Surreal Pop Editorial

- 色彩：天空蓝配橙黄、草绿配白黑、深蓝配水果色等高识别组合。
- 素材：超比例水果、金鱼、云、泡泡、购物车、餐具、包装托盘、警示牌、锁链或日常商品。
- 字体：巨大脚本字、粗衬线、漫画爆炸框、斜体编辑文字。
- 版式：人物与荒诞商品形成尺寸错位，像 2000 年代创意杂志广告；保持一个强概念，不要堆成无主题素材墙。

## 版式构建顺序

1. 确定一句视觉概念，例如“粉黑 gyaru 大头贴主页”“酸绿 club 专辑封面”或“冰蓝数码产品目录”。
2. 选定主角：人物、组合、产品或主题物件。让主角占画面约 35%-65%，不要缩在一个小相框里。
3. 建立主标题：标题占画面宽度约 45%-95%，可在顶部、底部或斜穿画面，允许被人物局部遮住。
4. 复制主角的 2-4 个细节版本：小型全身、脸部特写、眼睛/嘴唇局部、拍立得、手机屏幕、缩略图或半调网点副本。
5. 加入 3-7 个结构化信息组件：标签、条码、编号、短句、对话框、列表、日期、播放器、文件窗口、票据或警示贴。
6. 加入 4-10 个与主题相关的道具或装饰；优先使用能讲述人物、音乐、造型或年代的具体物件。
7. 用少量星芒、气泡、链条、贴纸边、扫描线、纸张撕口或印刷噪点连接空隙。装饰是胶水，不是主体。
8. 最后检查阅读顺序：主标题 -> 主角 -> 次标题/姓名 -> 小图与信息 -> 装饰细节。

## 人物与参考图

- 把参考图当作等待重新设计的原始素材，而不是风格参考。即使原图是日常照、证件照、现代棚拍、普通商品图或其他审美，也必须进行完整的 Y2K 艺术指导与视觉改造。
- 有参考人物时，只需保持可辨识的身份特征、脸部、肤色、人物数量和必要的身体特征，不要把人物替换成陌生人。主动重新设计发型细节、妆容、服装、饰品和姿态，使其符合选中的 Y2K 分支；用户明确要求保留的项目除外。
- 有参考产品或物件时，保持核心轮廓、功能和识别特征，但主动重做材质、配色、包装、陈列环境和周边道具；用户明确要求保留的品牌或文字除外。
- 第一张参考图默认提供主角身份或核心对象；后续参考图用于补充身份、姿态或不同角度。不要默认沿用任何参考图的背景、服装、道具、配色、文字和排版。
- 对同一人物进行设计性复用：一个大抠图或大照片，加 2-4 个不同尺寸的副本。副本可以矩形裁切、白边抠图、心形洞口、手机屏幕、半调网点或单色印刷处理。
- 不要把每张上传图等尺寸排成规整相册。根据重要性改变尺寸、裁切和层级。
- 图片可有低清数码感、直闪、轻微过曝、压缩噪点或扫描纹理，但必须服务于海报拼贴；不要只生成一张仿实拍照片再贴几个图标。
- 即使用户只上传图片而没有 prompt，也要自行生成完整设计所需的标题、短标签、年代道具、服装造型、背景和信息组件；不要等待用户补充，也不要沿用上传图的普通风格。

## 字体与文字系统

一张海报使用 3-5 种明确角色，不要所有字都用同一种字体或同一种铬效果。

- 主标题：超大铬银/粉色充气 3D 无衬线、粗窄黑体、黑体描边字、Old English、尖锐金属字或大型脚本字，选择其一。
- 次标题：粗体无衬线、日文粗圆体、韩文展示体或斜体字，使用白/黑/粉描边保证可读。
- 信息字：Tahoma/Verdana 风格系统字、等宽像素字、窄体杂志字、条码标签字。
- 情绪字：少量高对比衬线或花体，只用于 1-3 个短词，不要铺满。
- 允许中英日韩混排，但文字必须有层级和语义。优先准确呈现用户给出的标题、姓名、日期和短句。
- 用户未提供文案时，只生成少量连贯的短语、编号和栏目词；不要生成大段乱码，不要伪造水印、社交账号或设计师署名。
- 大字可使用挤压、拉伸、斜切、弧形、3D 挤出、黑白双描边、金属高光或投影。小字保持平面和清晰，形成对比。

## 材质与年代感

- 组合 2-4 种材质即可：铬金属、充气塑料、透明凝胶、闪粉、珍珠、皮革、动物纹、粗糙纸张、半调网点、扫描线或 JPEG 压缩感。
- 照片边缘可以是干净抠图、白色贴纸轮廓、矩形硬裁切、撕纸边或羽化叠化；同一张图不要全部混用。
- 使用明显的层间遮挡：人物压标题，标题压背景，手机压人物边缘，小贴纸压信息框。避免所有元素彼此留出均匀间距。
- 允许少量故意低保真：像素化图标、老屏幕摩尔纹、复印噪点、印刷网点和轻微错版；主角五官和主标题仍应清楚。

## 必须避免

- 不要生成“中央空白照片框 + 四周 Y2K 小图标”的边框模板。
- 不要只用柔和渐变、几颗星星、蝴蝶和 chrome 字就宣称完成 Y2K 海报。
- 不要现代极简、电商白底、SaaS 卡片、均匀网格、规整相册、空旷留白或单一壁纸图案。
- 不要把所有元素缩小后平均散落；至少有一个夸张的大标题和一个占主导的视觉主体。
- 不要让贴纸数量多于有意义的照片、标题和信息组件。
- 不要随机混合所有分支，不要无故加入赛博朋克雨夜、蒸汽波落日、80 年代霓虹网格、动漫插画或奢侈品极简风。
- 不要伪造现成品牌 Logo、艺术家签名、平台水印或社交媒体账号；用户明确提供的品牌文字除外。

## 输出要求

- 直接输出一张完成度高的最终海报，不要输出分析、草图、候选方案、教程或纯素材板。
- 画面要满版、有主次、有编辑节奏，缩略图状态也能识别主角和标题，放大后仍有可看的信息细节。
- 默认采用竖版海报；遵循生图台中用户已选择的比例和尺寸。
- 用户没有额外 prompt 时，每次独立随机选择一个 Y2K 分支，并自行生成该分支需要的完整内容与设计元素；不要总是选择同一种分支。
